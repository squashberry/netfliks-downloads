BEFORE YOU INSTALL

Windows may show a security warning.

Netfliks is a new Windows app and may not yet have an established Microsoft Defender SmartScreen reputation. That warning does not by itself mean the app is malicious.

01

If Windows says “Windows protected your PC”

Click More info in the warning window.

02

Review the publisher and file

Make sure you downloaded Netfliks from this official website and that the file is NetfliksSetup.exe.

03

Continue

After selecting More info, Windows may reveal the Run anyway option. Select it only when you trust the download source.

ⓘ

SmartScreen can warn about new or infrequently downloaded apps while reputation is being established. Keep Windows security enabled.
